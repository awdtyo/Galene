About Galene

Galene is a multi-agent marine intelligence assistant for the Indian coast. A deterministic risk engine reads live and fallback marine data, geospatial boundaries and IMD warnings, then a reporting agent writes the advisory.

Every number, verdict, boundary, warning and citation on this page comes from the Galene backend. Where the API returns nothing, the interface says Data unavailable — nothing is estimated in the browser. Boundaries are simplified and are not for navigation.
